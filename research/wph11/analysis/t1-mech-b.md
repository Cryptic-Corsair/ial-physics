# WPH11 Topic 1 mechanics gap analysis — agent b (2021-Oct → 2022-Oct)

**Question:** could a student who read ONLY the site's WPH11 notes gain every mark on these papers?

**Method.** Coverage baseline read in full (T1/A–C specs 1–22, T2/A–B specs 23–32, plus `wph11.ts` topic-page def cards / tips / recaps — treated as taught knowledge). For each session the MS was read first, then the QP. Blocks labelled "Mark scheme wording", "Examiner's report", "Not accepted" and the `wph11.ts` def cards ("Resultant force", "Terminal velocity") count as taught. Where a verdict was uncertain the real notes files (`notes-ph01-a/b/c.ts`, `notes-ph02-a/b.ts`) were grepped (line numbers cited). Verdict rule applied strictly: a taught method applied in a new context = COVERED; a fact/skill/convention the notes never state = GAP; taught in part = PARTIAL with the missing piece named.
